# v0.6.0 視覺設計與素材紀錄

## 採用方向

2026-09-07，採用使用者選定的方案 1：深石墨與紙白交替、震欣紅點綴、左文右圖主視覺、連續能力佐證列、四步製程、材料與樣品橫向展示、案例帶與雙欄聯絡區。

借鑑參考網站的留白、字級層次與克制動態，不搬用 Apple／OpenAI 的商標、程式碼、照片或影片。主視覺為本專案生成的原創製程概念示意，不是設備運轉紀錄或精確製程模擬。

## 不可偏離的產品事實

- 震欣的 MIM 燒結使用**真空燒結爐**。製程區使用既有 `sintering-furnace.jpg` 實照，禁止替換為連續爐、輸送帶火焰爐或概念圖中的錯誤設備。
- 中、英、日製程與設備說明同步使用真空燒結用語；這是震欣設備說明，不宣稱所有 MIM 業者只使用同一種爐型。
- `100g` 保持「MIM 零件重量能力」，不可誤寫為最小生產重量。
- 保留既有 `1000+`、ISO 9001:2015 與 X-RAY 能力資料；不增加未經證實的公差、良率、密度或客戶品牌。
- 材料、應用與樣品圖片保留原專案實物素材，不把生成圖當成已出貨案例。
- 日語材料名稱保留「ハイス鋼（HSS）」，首次解釋保留「高速度工具鋼」。

## 版型與互動

- 內容最大寬 1320px；深色 `#0b1013`、紙白 `#f3f3f3`、品牌紅 `#e40012`。
- 桌面雙欄 Hero，手機改為文字、CTA、主圖、控制列的單欄順序。
- 主視覺用原創粉末／零件底圖加輕量 Canvas2D 粒子；提供暫停、重播、手動階段及方向鍵／Home／End。
- 非可見區域、隱藏頁籤停止 RAF；減少動態、省流量、無 Canvas 或無 JS 時呈現靜態主圖。沒有新增視差捲動鎖定或自動捲頁。
- 材料可原生水平捲動與鍵盤瀏覽；樣品另提供有邊界停用狀態的前後按鈕。
- 手機導覽可捲動，語言選單在正常排版流內展開；Esc 先關語言選單，再關導覽。無 JS 保留導覽連結。
- 詢問表單只在本機整理草稿。訪客可預覽、開啟郵件草稿或下載文字；不自動寄信、不上傳圖面、不儲存個資。長篇需求可能超出部分郵件程式的 mailto 限制，應使用下載草稿。
